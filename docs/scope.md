# MVPスコープ定義

## MVPでやること

### 通信モード

- ローカル（1台共有）のみ

### ゲーム機能

| 機能 | 詳細 |
|---|---|
| プレイヤー登録 | 名前入力、人数設定 |
| ゲーム設定 | テーマ・難易度・サイクル数 |
| ターン進行 | ターゲットローテーション・お題表示 |
| 秘密入力 | 端末回し + 覗き見防止 |
| 得点計算 | 一致度ベースのスコアリング |
| 結果表示 | ターンごとの結果 |
| 最終順位表示 | 総合スコア・ランキング |
| 再戦 | 同じメンバーで再プレイ |

### 画面構成

1. 通信設定画面（MVPではローカル固定）
2. ゲーム設定画面
3. ゲーム進行画面
4. 終了画面

---

## MVPでやらないこと

| 機能 | 理由 | 予定Phase |
|---|---|---|
| 複数台通信（ネット） | 実装コスト・MVPで検証不要 | Phase 2 |
| 複数台通信（Bluetooth） | 実装コスト高 | Phase 3 |
| 分析機能（一致率・相関） | コア体験の検証が先 | Phase 2 |
| 課金（広告削除・お題追加） | ユーザーベースが先 | Phase 3 |
| アカウント機能 | MVPでは不要 | Phase 2 |
| 保存・復帰 | MVPではセッション完結 | Phase 2 |
| リアルタイム同期 | ローカルモードでは不要 | Phase 2 |
| ソーシャル機能 | コア体験の検証が先 | Phase 4 |

---

## スコープ判断基準

MVPに含めるかの判断：

> **「ローカルで1ゲーム完走できるか」に必要かどうか**

- 必要 → MVP
- あると良い → Phase 2以降
- なくても遊べる → 後回し
