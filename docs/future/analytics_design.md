# 将来拡張参考資料: 分析・価値観可視化設計

> この文書はPhase 2以降の参考資料です。MVP実装には含まれません。

## 概要

ゲーム結果から価値観の可視化・プレイヤー間の相関分析を行う機能。

## 分析項目

| 項目 | 説明 | Phase |
|---|---|---|
| 一致率 | プレイヤーペアごとの予測一致率 | Phase 2 |
| プレイヤー相関 | 誰と誰の価値観が近いか | Phase 2 |
| ジャンル傾向 | テーマ別の得意・不得意 | Phase 2 |
| スコア推移 | ゲームごとのスコア変化 | Phase 2 |

## 価値観可視化

> 「友達の価値観がわかる」というコアコンセプトの具現化

- プレイヤー間の一致度をグラフ化
- 「あなたと○○は価値観が近い」のような表示
- 過去のゲーム横断での傾向分析

## データ要件

- ゲーム履歴の保存が必要（MVPでは未実装）
- Answer に matchRate フィールドを追加
- Player に odaiStats フィールドを追加
