# 将来拡張参考資料: 開発者モード（Dev Mode）

> この文書はPhase 2以降の参考資料です。MVP実装には含まれません。

## 概要

開発・QA・スクリーンショット作成時の検証速度を上げる「開発者モード」。プレイヤー登録やお題進行のショートカット、状態の可視化、データリセットなどを 1 か所に集約する。

有効化と表示制御は [feature_flags.md](feature_flags.md) の仕組みに乗せる（dev mode 自体はフラグ群の最大の利用先になる）。

## 背景・動機

- ターン進行のたびにカバー画面 → ランキング入力 → 結果アニメ … をクリックするのは検証時に大きな摩擦になる（[キーボードショートカット対応](../../GuessRank/GuessRank/Views/) で部分緩和済みだが、状態再現や複数ターンの一括進行は未対応）
- App Store 用スクリーンショット撮影時、特定のお題・人数・スコア状態を毎回手動で再現するのが煩雑
- 不具合報告の再現確認時に、対象のお題・順序・seed を固定したい
- 履歴・フィードバック・スナップショットの累積データを開発端末上でクリーンに戻したい

## 機能要件

### クイックスタート

- ワンタップで「ダミープレイヤー 4 名 + デフォルトテーマ + ノーマルモード」の状態でゲームを開始
- ターン数・人数・モードのプリセットを複数用意（`Quick4P` / `Hard6P` / `Solo` など）

### お題固定モード

- 抽選アルゴリズムをバイパスし、指定した topic ID（または ID リスト）を順に出題
- スコア計算ロジックの再現テスト・スクリーンショット撮影で利用

### スキップ / 高速化

- カバー画面を自動でスキップ（覗き見防止が要らないソロ検証用）
- ターン結果のアニメーション速度を 4x に
- 「全プレイヤー自動入力」モード（ランダム or 固定パターンで埋める）

### デバッグオーバーレイ

- 画面右上に半透明オーバーレイで以下を表示
  - 現在のターン番号 / フェーズ / 現在の入力プレイヤー
  - 直近スコア計算の内訳（一致点 + 部分点）
  - 抽選で除外されたお題と理由（最近ブロック・最近出題）
- タップで折りたたみ可能

### データリセット

- 履歴 / フィードバック / セッションスナップショット / UserDefaults を選択してリセット
- 確認ダイアログ必須（誤タップ防止）

### シード固定

- ターゲットプレイヤー順・お題抽選を再現可能にする `seed` を Game 開始時に指定
- 同じ seed で起動すれば毎回同じ進行になる

### 状態スナップショット入出力

- 任意のタイミングで現在の `GameSession` を JSON エクスポート
- 同 JSON をインポートしてその状態からゲームを再開
- 既存の [topic_feedback の JSON エクスポート](../features/topic_feedback/spec.md) と同じファイル共有 UI を流用

## 有効化と動線

- 有効化条件は [feature_flags.md](feature_flags.md) に従う
  - DEBUG ビルド: `devModeEnabled` のデフォルトを ON、設定画面に「開発者」セクションを常時表示
  - RELEASE / TestFlight: デフォルト OFF。隠し動線（設定画面ロゴ N 回タップ）で開放するかは別途検討
- 開発者セクションの位置は `GameSettingsView` 末尾、もしくは独立した `DeveloperSettingsView`

## 影響範囲

- **新規**: `Views/DeveloperSettingsView.swift`, `Views/Debug/DebugOverlay.swift`, `Services/GameSessionExporter.swift`
- **GameSetupViewModel**: クイックスタート（ダミープレイヤー注入）エントリポイント
- **GameProgressView**: デバッグオーバーレイの差し込み（フラグ参照）
- **GameEngine / TopicService**: seed・固定お題ID の受け入れ
- **GameSettingsView**: 開発者セクションへの導線
- **アニメーション各所**: 速度倍率の参照（環境値経由）

## やらないこと

- リリース版での恒常的な開発者機能の露出（審査リスク・誤操作リスク）
- 本番ユーザー向けの「上級者モード」とは目的・想定ユーザーが異なるため、UI も配置も明確に分離する
- リモート操作（リモート実行のフラグ反映は [feature_flags.md](feature_flags.md) のリモート層に切り出す）
