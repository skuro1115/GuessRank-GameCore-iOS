# 将来拡張参考資料: お題リモート配信機能

> この文書はPhase 2以降の参考資料です。MVP実装には含まれません。

## 概要

お題データをアプリ内蔵のみに依存せず、外部サーバーから定期的にダウンロードして追加・更新する機能。

## 背景・動機

- アプリアップデートなしでお題を追加できるようにしたい
- 季節・トレンドに合わせた旬なお題を配信したい
- プレイモード追加時にモード別のお題セットを柔軟に拡充したい

## 機能要件

### お題のダウンロード

- アプリ起動時またはバックグラウンドで定期的にお題データを取得
- 差分ダウンロード（新規・更新分のみ取得）でデータ量を抑える
- オフライン時はローカルキャッシュ済みのお題で動作する

### お題データの管理

- ダウンロード済みお題はローカルに永続化（SwiftData等）
- バンドル内蔵お題 + ダウンロードお題を統合して使用
- お題ごとにバージョンや配信日時を持ち、重複・競合を防ぐ

## サーバー側の検討事項

- 配信形式: JSON（軽量・パースしやすい）
- ホスティング: Firebase / Supabase / 静的JSON配信（S3等）など
- 認証: 不要（公開データ）またはアプリキーによる簡易認証
- 費用: 静的JSON配信であればほぼ無料で運用可能

## 影響範囲

- **TopicService**: リモートお題の取得・マージロジック追加
- **データモデル**: お題にソース（bundled / remote）・バージョン情報を追加
- **GameConfig**: ダウンロード済みお題のフィルタリング対応
- **設定画面**: 手動更新ボタン・最終更新日時の表示
