# 将来拡張参考資料: お題ブロック機能

> この文書はPhase 2以降の参考資料です。MVP実装には含まれません。

## 概要

不適切・つまらないと感じたお題をブロックし、以降のゲームで表示されないようにする機能。

## 機能要件

### ブロック操作

- ゲーム中のお題表示画面からブロック可能（長押しメニュー等）
- ブロック理由は任意（不適切 / つまらない / その他）
- ブロック時に確認ダイアログを表示

### ブロック管理

- ブロック済みお題一覧を設定画面から確認可能
- 個別またはー括でブロック解除できる

### お題選出への影響

- ブロック済みお題はお題選択候補から除外される
- ブロック数が多く候補が少なくなった場合は通知する

## データ要件

- `UserDefaults` または `SwiftData` でブロック済みお題IDを永続化
- 保存項目: お題ID、ブロック日時、理由（任意）

## 影響範囲

- **TopicService**: お題取得時にブロック済みをフィルタリング
- **ゲーム中UI**: ブロック操作の導線追加
- **設定画面**: ブロック一覧・解除UIの追加
