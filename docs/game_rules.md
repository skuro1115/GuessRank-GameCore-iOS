# ゲームルール

## ゲーム名

GuessRank

## 一言で言うと

**「友達の好みの順位を当てるパーティーゲーム」**

お題に対してターゲットが決めた1位・2位・3位の順番を、他のプレイヤーが予想する。
競馬の「三連単」のように、順番まで完全に当てると高得点。

---

## 準備

- プレイヤー: 2〜6人
- 端末: スマホ1台（みんなで回す）
- 所要時間: 1サイクル（全員が1回ずつ出題）で約10〜15分

> 詳細: [通信設定 仕様](features/communication_settings/spec.md)

---

## ゲーム設定

> 詳細: [ゲーム設定 仕様](features/game_settings/spec.md)

| 項目 | 選択肢 | デフォルト |
|---|---|---|
| ジャンル | 食べ物 / 趣味 / ランダム | ランダム |
| 難易度 | かんたん / ふつう / むずかしい | ふつう |
| サイクル数 | 1〜3 | 1 |
| 人数 | 2〜6 | 3 |

ジャンルと難易度は **お題データプールのフィルタ条件** として使われる。
設定に合致するお題がデータプールからランダムに選出され、各ターンで1問ずつ表示される。

> 難易度による違い（想定）: 選択肢の類似度や予想のしにくさで調整

---

## ゲームの流れ

> 詳細: [ゲーム進行 仕様](features/game_progress/spec.md)

```
① お題が表示される（ターゲット名 + 質問 + 選択肢を全員で見る）
    ↓
② ターゲットが「自分の好みの順位（1位〜3位）」を決める
    ↓
③ 他のプレイヤーが1人ずつ端末を受け取り、
   「ターゲットはどの順番で好きか」を予想して入力する
   （他の人の回答は見えない）
    ↓
④ 全員の回答が揃ったら結果発表 → 次のターンへ
```

これを全員分やったら **1サイクル完了**。
サイクル数は事前に設定でき、設定サイクル分だけ繰り返す。

---

## お題とデータプール

お題はアプリに内蔵された **データプール** から自動で選ばれる。
プレイヤーがお題を考える必要はない。

### お題の構成

各お題は以下の要素を持つ:

- **質問文**: 「昼に食べたいのは？」
- **選択肢**: 3つ（例: 寿司 / ラーメン / カレー）
- **ジャンル**: 食べ物 / 趣味 / ランダム など
- **難易度**: かんたん / ふつう / むずかしい

### お題の例

| ジャンル | お題 | 選択肢 |
|---|---|---|
| 食べ物 | 「昼に食べたいのは？」 | 寿司 / ラーメン / カレー |
| 趣味 | 「休日にやりたいのは？」 | 映画 / ゲーム / 散歩 |
| ランダム | 「もらって嬉しいのは？」 | 花束 / お菓子 / 手紙 |

ターゲットの **個人の好み** の順位を当てるのがポイント。
正解はターゲットの主観なので、「友達をどれだけ理解しているか」が試される。

### フィルタリング（将来実装可）

ゲーム設定のジャンル・難易度でデータプールを絞り込める。
MVP では全お題からランダム選出でも可。

### お題を変える

表示されたお題が場の雰囲気に合わない・答えにくい場合、**「お題を変える」ボタン**で別のお題に変更できる。

- ゲームルール上の制限ではなく、場を円滑にするためのオプション
- 回数制限なし（何度でも変更可能）
- 同じお題が再度出ないように管理される

## スコア

| 結果 | 得点 | 説明 |
|---|---|---|
| 完全一致（三連単） | 100点 | 1位・2位・3位すべて的中 |
| 2つ一致 | 50点 | 3つ中2つの順位が合っている |
| 1つ一致 | 20点 | 3つ中1つの順位が合っている |
| 不一致 | 0点 | すべて外れ |

各ターンで予想者全員がそれぞれスコアを獲得し、全ターン終了後の合計で順位を決定する。

---

## 結果・終了

> 詳細: [終了画面 仕様](features/end_screen/spec.md)

全ターン終了後、スコアの合計で最終順位を決定する。
同点の場合は同順位。再戦も可能。

---

## 用語

| 用語 | 意味 |
|---|---|
| ターン | 1人が出題し、全員が回答して結果発表するまでの1区切り |
| サイクル | 全員が1回ずつターゲットになる一巡。サイクル数 × 人数 = 総ターン数 |
| ターゲット | そのターンでお題を出す人。自分の好み順位を決める |
| 予想者 | ターゲット以外の全員。ターゲットの好みの順位を予想する |
| 三連単 | 1位〜3位を完全に当てること（100点） |
| データプール | お題の一覧データ。ジャンル・難易度でフィルタ可能 |

## 覗き見防止（ローカルモード）

> 詳細: [通信設定 仕様](features/communication_settings/spec.md)

1台のスマホをプレイヤー間で回して使う。覗き見防止はカバーオーバーレイで実現:

1. 順位入力画面の上に「○○さんの番です」カバーを被せる
2. タップでカバーを外して入力を開始する
3. 入力確定後は即座に次の人のカバー付き画面に遷移する
4. 全員の入力が終わるまで結果は表示されない
