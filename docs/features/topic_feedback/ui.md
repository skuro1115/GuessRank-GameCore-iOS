# お題フィードバック — UI

## ゲーム画面の操作 (`TopicView`)

### 右上のFBボタン

`showTopic` フェーズの画面右上に2つの円形ボタンを配置：

```
[👍]  [⋯]
```

| ボタン | アイコン | 動作 |
|---|---|---|
| 面白い | `hand.thumbsup` (未状態) / `hand.thumbsup.fill` (登録済) | タップで like 登録／解除をトグル |
| その他のFB | `ellipsis` | タップで Menu を表示 |

- `👍` 登録時はオレンジ色に変化、未登録は `.secondary` 色
- いずれも `currentTopic == nil` の時は `disabled`

### `⋯` Menu の中身

```
ブロック: 不適切      （hand.raised）
ブロック: つまらない  （hand.raised）
ブロック: その他      （hand.raised）
理由なしでブロック    （hand.raised.slash, destructive）
```

選択するとブロックストアに登録され、即座にお題が別のものに差し替わる。

### フィードバックバナー

操作後、画面上部にトースト型のバナーを約1.5秒表示：

| 操作 | メッセージ |
|---|---|
| like 登録 | 「面白いお題として記録しました」 |
| like 解除 | 「「面白い」を取り消しました」 |
| ブロック（理由あり） | 「お題をブロックしました（{理由名}）」 |
| ブロック（理由なし） | 「お題をブロックしました」 |

### `rankingInput` フェーズでの挙動

`showTopic` 以外では `viewModel.blockCurrentTopic` / `toggleLikeCurrentTopic` ともに no-op。ボタンは disabled。

## 設定画面 (`TopicSettingsView`)

ゲーム設定画面のギアアイコンから開くシート。`showTopic` 以外でも閲覧・操作可能。

### セクション構成

```
1. お題履歴             ── プレイ済み件数 / 履歴リセット
2. ブロック中のお題（N件）── 一覧 + 個別解除 + 全て解除
3. 「面白い」お題（N件）  ── 一覧 + 個別解除 + 全て解除
4. データエクスポート     ── ShareLink で JSON 書き出し（FB 0件時は非表示）
```

### 各セクションの詳細

#### ブロック / 「面白い」セクション

エントリが0件の場合：

- ブロック: 「ブロック中のお題はありません」
- 面白い: 「「面白い」として記録されたお題はありません」

エントリありの場合：

```
質問文（topic_lookup から取得; 見つからない場合は ID）
理由（ブロックのみ・ある場合）caption
[解除] ボタン（個別）
```

最下部に `[全て解除]`（destructive、確認アラート付き）。

#### 操作と確認アラート

| 操作 | ハンドラ | 確認アラート |
|---|---|---|
| ブロック「解除」 | `unblock(_:)` → refresh | なし |
| ブロック「全て解除」 | `clearBlocks()` | 「ブロックを全て解除しますか？」 |
| like「解除」 | `unlike(_:)` → refresh | なし |
| like「全て解除」 | `clearLikes()` | 「「面白い」記録を全て解除しますか？」 |

### データエクスポートセクション

```
[共有アイコン] FBデータをエクスポート
```

タップで iOS 標準の ShareSheet が開く。共有内容：

- ファイル名: `guessrank_feedback_YYYY-MM-DD.json`
- ファイル本体: 永続化されている全FBエントリの pretty-printed JSON
- ローカル一時ファイル経由（`FileManager.default.temporaryDirectory`）

フッターテキスト：
「ブロック・「面白い」のFBをJSONファイルとして書き出します。送信は行いません。機種変更時の引き継ぎや、開発者へのフィードバック共有にご利用ください。」

> 送信は **iOS 標準 ShareSheet を介してユーザーが宛先を選ぶ** ため、アプリ自体は外部送信を行わない。プライバシーポリシー上のデータ送信記載は不要。
