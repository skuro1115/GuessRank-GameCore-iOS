# ゲーム設定 — 仕様

> ゲームルール全体は [game_rules.md](../../game_rules.md) を参照

## 概要

ゲーム開始前にジャンル・難易度・サイクル数・人数を設定し、プレイヤーを登録する。

## ビジネスルール

1. すべての設定項目を入力しないとゲームを開始できない
2. 人数は **2人以上** が必須（1人ではゲームが成立しない）
3. サイクル数は **1以上**
4. 1サイクル = 全員が1回ずつ出題。**総ターン数 = サイクル数 × 人数**
7. 所要時間の目安を表示する: **総ターン数 × 30秒**
5. プレイヤー名は **空文字不可**、**重複不可**
6. ローカルモードでは人数を手動入力（将来の複数台では接続人数で決定）

## 設定項目

| 項目 | 型 | 制約 | デフォルト |
|---|---|---|---|
| ジャンル | Genre | 選択式 | ランダム |
| 難易度 | Difficulty | easy / normal / hard | normal |
| サイクル数 | int | 1以上 | 1 |
| 人数 | int | 2以上 | 3 |

## お題の選出方式

お題はプレイヤーが入力するものではなく、アプリ内蔵の **データプール** からランダムに選出される。

- ジャンル・難易度は **データプールのフィルタ条件** として機能する
- フィルタに合致するお題の中からランダムに1問ずつ選出される
- 同一ゲーム内でお題が重複しないようにする
- MVP ではフィルタリング未実装でも可（全お題からランダム選出）

## ジャンル一覧（MVP）

| ジャンル | 説明 |
|---|---|
| 食べ物 | 食べ物に関するお題 |
| 趣味 | 趣味・娯楽に関するお題 |
| ランダム | 全ジャンル混合 |

## プレイヤー登録

- 人数を設定後、各プレイヤーの名前を入力
- 入力順がプレイヤー順（order）になる

## 関連モデル

> データモデルの定義は [data_model.md](../../data_model.md) を参照

- GameConfig: ジャンル・難易度・サイクル数・人数
- Player: 名前・順番
