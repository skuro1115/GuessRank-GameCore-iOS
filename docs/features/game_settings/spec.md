# ゲーム設定 — 仕様

## 概要

ゲーム開始前にテーマ・難易度・サイクル数・人数を設定し、プレイヤーを登録する。

## ビジネスルール

1. すべての設定項目を入力しないとゲームを開始できない
2. 人数は **2人以上** が必須（1人ではゲームが成立しない）
3. サイクル数は **1以上**
4. 1サイクル = 全員が1回ずつ出題。**総ターン数 = サイクル数 × 人数**
5. プレイヤー名は **空文字不可**、**重複不可**
6. ローカルモードでは人数を手動入力（将来の複数台では接続人数で決定）

## 設定項目

| 項目 | 型 | 制約 | デフォルト |
|---|---|---|---|
| テーマ | String | 選択式（将来カスタム追加） | — |
| 難易度 | Difficulty | easy / normal / hard | normal |
| サイクル数 | int | 1以上 | 1 |
| 人数 | int | 2以上 | 3 |

## テーマ一覧（MVP）

> テーマとお題の詳細は別途定義が必要

| テーマ | 説明 |
|---|---|
| 食べ物 | 食べ物に関するお題 |
| 趣味 | 趣味・娯楽に関するお題 |
| ランダム | 混合お題 |

## プレイヤー登録

- 人数を設定後、各プレイヤーの名前を入力
- 入力順がプレイヤー順（order）になる

## 関連モデル

> データモデルの定義は [data_model.md](../../data_model.md) を参照

- GameConfig: テーマ・難易度・サイクル数・人数
- Player: 名前・順番
