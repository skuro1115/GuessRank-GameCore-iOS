# ゲーム設定 — テストケース

## 正常系

| # | テスト内容 | 操作 | 期待結果 |
|---|---|---|---|
| N-01 | 基本設定完了 | テーマ選択、難易度normal、サイクル1、人数3 → 次へ | プレイヤー登録画面に遷移 |
| N-02 | プレイヤー登録完了 | 3人分の名前入力 → ゲーム開始 | ゲーム進行画面に遷移 |
| N-03 | 難易度変更 | easy → hard に切り替え | 設定が反映される |
| N-04 | サイクル数変更 | +ボタンで2に変更 | サイクル数が2に変わる |
| N-05 | 人数変更 | 4人に変更 → 次へ | 4人分の入力フィールドが表示 |

## 異常系

| # | テスト内容 | 操作 | 期待結果 |
|---|---|---|---|
| E-01 | テーマ未選択で次へ | テーマ未選択 → 次へ | エラー「テーマを選択してください」 |
| E-02 | プレイヤー名空欄 | 1人分の名前を空のまま → ゲーム開始 | エラー「名前を入力してください」 |
| E-03 | プレイヤー名重複 | 同じ名前を2人分入力 → ゲーム開始 | エラー「名前が重複しています」 |

## 境界値

| # | テスト内容 | 操作 | 期待結果 |
|---|---|---|---|
| B-01 | 最小人数 | 人数を2に設定 | 設定可能、2人分の入力フィールド |
| B-02 | 人数1への減少 | 人数2の状態で - タップ | 2のまま変わらない |
| B-03 | サイクル数1への減少 | サイクル1の状態で - タップ | 1のまま変わらない |
| B-04 | 総ターン数確認 | サイクル2、人数4 | 総ターン数 = 8 |
