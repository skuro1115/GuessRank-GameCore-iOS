# ゲーム設定 — UI定義

## 画面名

### GameSettingsScreen（設定画面）

```
┌─────────────────────────┐
│  ゲーム設定               │
│                         │
│  テーマ: [▼ 選択]        │
│  難易度: [Easy|Normal|Hard] │
│  サイクル数: [- 1 +]     │
│  人数: [- 3 +]           │
│                         │
│  [次へ]                  │
└─────────────────────────┘
```

### PlayerSetupScreen（プレイヤー登録画面）

```
┌─────────────────────────┐
│  プレイヤー登録           │
│                         │
│  1. [名前を入力]         │
│  2. [名前を入力]         │
│  3. [名前を入力]         │
│                         │
│  [ゲーム開始]            │
└─────────────────────────┘
```

## 表示項目

### GameSettingsScreen

| 項目 | UI部品 | 表示形式 |
|---|---|---|
| テーマ | Dropdown | 選択式 |
| 難易度 | SegmentedControl | 3択 |
| サイクル数 | Stepper | 数値（1刻み） |
| 人数 | Stepper | 数値（1刻み） |

### PlayerSetupScreen

| 項目 | UI部品 | 表示形式 |
|---|---|---|
| プレイヤー名 | TextField | 人数分のフィールド |
| 番号 | Text | 1始まり連番 |

## 操作

| 操作 | 動作 |
|---|---|
| テーマ選択 | ドロップダウンでテーマを選ぶ |
| 難易度選択 | セグメントで切り替え |
| サイクル数 ± | 1ずつ増減（最小1） |
| 人数 ± | 1ずつ増減（最小2） |
| 次へタップ | プレイヤー登録画面へ遷移 |
| ゲーム開始タップ | バリデーション後、ゲーム進行画面へ遷移 |

## バリデーション

| 条件 | エラーメッセージ |
|---|---|
| テーマ未選択 | 「テーマを選択してください」 |
| プレイヤー名が空 | 「名前を入力してください」 |
| プレイヤー名が重複 | 「名前が重複しています」 |

## 遷移

| トリガー | 遷移先 |
|---|---|
| 次へタップ（設定画面） | PlayerSetupScreen |
| ゲーム開始タップ | GameProgressScreen |
| 戻るタップ | CommunicationSettingsScreen |
