# ゲーム進行 — UI定義

## 画面構成

ゲーム進行は複数の画面で構成される。

---

### 1. GameProgressScreen（ターン開始）

出題者とターン情報を表示。

```
┌─────────────────────────┐
│  ターン 1 / 6            │
│                         │
│  出題者:                 │
│  ◉ たろう               │
│                         │
│  [お題を見る]            │
└─────────────────────────┘
```

| 項目 | 表示形式 |
|---|---|
| ターン番号 | 「ターン {current} / {total}」 |
| 出題者名 | プレイヤー名を大きく表示 |

---

### 2. TopicScreen（お題表示）

出題者が確認するお題画面。

```
┌─────────────────────────┐
│  お題                    │
│                         │
│  「好きな食べ物は？」      │
│                         │
│  A. 寿司                │
│  B. ラーメン             │
│  C. カレー               │
│                         │
│  [出題者: 正解を入力]     │
└─────────────────────────┘
```

出題者が正解の順位を入力後:

```
┌─────────────────────────┐
│  正解を設定しました       │
│                         │
│  1位: ラーメン           │
│  2位: 寿司              │
│  3位: カレー             │
│                         │
│  [回答を集める]          │
└─────────────────────────┘
```

---

### 3. PassDeviceScreen（端末回し）

```
┌─────────────────────────┐
│                         │
│  📱 端末を渡してください   │
│                         │
│  次の回答者:              │
│  はなこ                  │
│                         │
│  [準備OK]               │
└─────────────────────────┘
```

---

### 4. AnswerInputScreen（回答入力）

```
┌─────────────────────────┐
│  はなこ の回答            │
│                         │
│  「好きな食べ物は？」      │
│  たろう はどう並べる？     │
│                         │
│  1位: [▼ 選択]          │
│  2位: [▼ 選択]          │
│  3位: [▼ 選択]          │
│                         │
│  [確定]                  │
└─────────────────────────┘
```

- ドラッグ&ドロップまたはドロップダウンで順位を並べ替え

---

### 5. AnswerConfirmScreen（回答確認）

```
┌─────────────────────────┐
│  この回答でよろしいですか？ │
│                         │
│  1位: ラーメン           │
│  2位: カレー             │
│  3位: 寿司              │
│                         │
│  [戻る]  [送信]          │
└─────────────────────────┘
```

---

### 6. TurnResultScreen（ターン結果）

```
┌─────────────────────────┐
│  ターン 1 結果            │
│                         │
│  正解: ラーメン > 寿司 > カレー │
│                         │
│  はなこ: 50点（2つ一致）   │
│  じろう: 100点（完全一致!）│
│                         │
│  [次のターンへ]           │
└─────────────────────────┘
```

最終ターンの場合:

```
│  [結果を見る]             │
```

---

## 操作一覧

| 操作 | 動作 |
|---|---|
| お題を見るタップ | TopicScreen へ遷移 |
| 正解入力 → 回答を集める | PassDeviceScreen へ遷移 |
| 準備OKタップ | AnswerInputScreen へ遷移 |
| 確定タップ | AnswerConfirmScreen へ遷移 |
| 送信タップ | 次の回答者の PassDeviceScreen or TurnResultScreen へ |
| 次のターンへタップ | 次ターンの GameProgressScreen へ |
| 結果を見るタップ | EndScreen へ遷移 |

## 遷移まとめ

```
GameProgressScreen → TopicScreen → PassDeviceScreen
→ AnswerInputScreen → AnswerConfirmScreen
→ PassDeviceScreen（次の回答者）or TurnResultScreen
→ GameProgressScreen（次ターン）or EndScreen（最終ターン）
```
