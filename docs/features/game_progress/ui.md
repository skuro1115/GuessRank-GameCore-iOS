# ゲーム進行 — UI定義

## 画面構成

ゲーム進行は **4種類の画面** で構成される。
各画面は背景色で役割を区別し、ゲームのリズムを演出する。

| 画面名 | 背景色 | 目的 |
|---|---|---|
| お題ボード | オレンジ〜黄 グラデーション | 全員でお題を確認 |
| プレイヤーコール | ターゲット=オレンジ / 予想者=シアン | 覗き見防止 + 次の人を呼ぶ |
| ランキング入力 | 役割に応じた薄い色 | 順位を並べ替えて入力 |
| ターンリザルト | 紫系 | 結果発表の特別感 |

---

### 1. お題ボード（TopicView）

```
┌─────────────────────────────┐
│  [ターン 1 / 6]              │  ← カプセルバッジ
│                             │
│  👤 ターゲット: たろう            │
│                             │
│    「好きな食べ物は？」        │  ← 大きく目立つ
│                             │
│  (A) 寿司                   │
│  (B) ラーメン                │  ← 色付き丸ラベル
│  (C) カレー                  │
│                             │
│  [👆 たろう が順位を決める]    │  ← オレンジボタン

  背景: オレンジ〜黄グラデーション
```

## 操作一覧

| 画面 | 操作 | 動作 |
|---|---|---|
| お題ボード | 「順位を決める」タップ | プレイヤーコール（ターゲット）へ |
| プレイヤーコール | 「タップして開始」 | ランキング入力へ |
| ランキング入力 | 「決定」タップ | 次のプレイヤーコール or ターンリザルトへ |
| ターンリザルト | 「次のターンへ」タップ | 次ターンのお題ボードへ |
| ターンリザルト | 「最終結果を見る」タップ | ファイナルリザルトへ |

## 遷移まとめ

```
お題ボード
  → プレイヤーコール（ターゲット）
  → ランキング入力（ターゲット）
  → プレイヤーコール（予想者A）
  → ランキング入力（予想者A）
  → プレイヤーコール（予想者B）
  → ランキング入力（予想者B）
  → ...
  → ターンリザルト
  → お題ボード（次ターン）or ファイナルリザルト（最終ターン）
```
