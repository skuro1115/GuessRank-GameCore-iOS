# ゲーム進行 — 仕様

## 概要

ゲームのメインループ。ターンごとに出題 → 回答収集 → 結果表示を繰り返す。
ローカルモードでは端末回しで実現する。

## ビジネスルール

1. 出題者はプレイヤー順にローテーションする
2. 出題者以外の全員が回答者となる
3. 回答は **秘密入力**（他プレイヤーに見えない）
4. 全員の回答が揃ったら結果を表示する
5. 結果表示後、次ターンへ進む or 最終ターンなら終了画面へ
6. 全ターン数 = サイクル数 × 人数

## ターン進行フロー

```
出題者表示 → お題表示 → 回答収集（端末回し） → 結果表示
```

### 回答収集（端末回し）の詳細

```
回答者Aに渡す画面 → A入力 → A確認 → 次の人に渡す画面 → 回答者Bに渡す画面 → ...
```

- 出題者は回答しない（スキップ）
- 各回答者は順番に端末を受け取り、入力する

## お題と回答形式

- お題: 3つの選択肢が提示される（例:「好きな食べ物は？ A.寿司 B.ラーメン C.カレー」）
- 回答: 出題者が選ぶ順位（1位〜3位）を予想して並べ替える
- 「三連単」= 1位・2位・3位の順序を完全に当てる

## スコア計算

| 一致度 | 得点 | 説明 |
|---|---|---|
| 完全一致（三連単） | 100点 | 1位〜3位すべて正解 |
| 2つ一致 | 50点 | 順位が2つ合っている |
| 1つ一致 | 20点 | 順位が1つ合っている |
| 不一致 | 0点 | すべて外れ |

> スコアロジックは独立した純粋関数として実装する（テスト容易性のため）

## 覗き見防止（ローカルモード）

1. 「次の人に渡してください」画面を必ず挟む
2. 入力画面では他人の回答を表示しない
3. 入力確定後は確認画面を挟む
4. 確認後は即座に「次の人に渡してください」画面に遷移

## 関連モデル

> データモデルの定義は [data_model.md](../../data_model.md) を参照

- GameSession: セッション全体の状態管理
- Turn: 各ターンの情報
- Answer: 各回答者の予想と得点
