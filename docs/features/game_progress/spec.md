# ゲーム進行 — 仕様

> ゲームルール全体は [game_rules.md](../../product/game_rules.md) を参照

## 概要

ゲームのメインループ。ターンごとに お題提示 → 順位入力 → 結果表示 を繰り返す。
ローカルモードでは1台の端末を回して実現する。

## 画面一覧

| 画面名 | View ファイル | 説明 |
|---|---|---|
| お題ボード | TopicView | お題と選択肢を全員で確認する |
| プレイヤーコール | CoverView | 次の入力者を呼び出す覗き見防止画面 |
| ランキング入力 | RankingInputView | 順位を並べ替えて入力する |
| ターンリザルト | TurnResultView | ターンの正解・スコア・累計順位を表示 |
| ファイナルリザルト | EndView | 全ターン終了後の最終順位 |

> ゲーム準備画面（GameSettingsView）は [game_settings/spec.md](../game_settings/spec.md) を参照

## ビジネスルール

1. ターゲットはプレイヤー順にローテーションする
2. ターゲット以外の全員が予想者となる
3. 回答は **秘密入力**（他プレイヤーに見えない）
4. 全員の回答が揃ったら結果を表示する
5. 結果表示後、次ターンへ進む or 最終ターンなら終了画面へ
6. 全ターン数 = サイクル数 × 人数

## ターン進行フロー

```
お題ボード → [プレイヤーコール → ランキング入力] × (1+予想者数) → ターンリザルト
```

### お題ボード（TopicView）

- お題がデータプールからランダムに選出される
- ターゲット名・質問文・3つの選択肢をまとめて表示
- **全員が一緒に見る画面**（秘密情報なし）
- 暖色系グラデーション背景で「ゲームの始まり」を演出

### プレイヤーコール（CoverView）

- 次の入力者の名前と役割（ターゲット/予想者）を表示
- **ターゲットのとき**: オレンジ系背景 + 王冠アイコン
- **予想者のとき**: シアン系背景 + 推理アイコン
- タップで入力画面に遷移（覗き見防止）

### ランキング入力（RankingInputView）

- ターゲット・予想者で共用する順位並べ替え画面
- ターゲット: 自分の好みで1位〜3位を決める
- 予想者: ターゲットの好みを予想して並べ替える
- 役割に応じたアクセントカラーで区別（ターゲット=オレンジ, 予想者=シアン）

### ターンリザルト（TurnResultView）

- 正解順位・各予想者のスコア・現在の累計順位を表示
- 紫系背景で「結果発表」の特別感を演出
- 最終ターンの場合は「最終結果を見る」ボタンに変化

## お題と回答形式

- お題はデータプールからランダムに選出される（プレイヤーが考える必要はない）
- 各お題には3つの選択肢がセットになっている（例:「好きな食べ物は？ A.寿司 B.ラーメン C.カレー」）
- ターゲット: 自分の好みで1位〜3位を決める
- 予想者: ターゲットが決めた順位を予想して並べ替える
- 「三連単」= 1位・2位・3位の順序を完全に当てる

## スコア計算

| 一致度 | 得点 | 説明 |
|---|---|---|
| 完全一致（三連単） | 100点 | 1位〜3位すべて正解 |
| 2つ一致 | 50点 | 順位が2つ合っている |
| 1つ一致 | 20点 | 順位が1つ合っている |
| 不一致 | 0点 | すべて外れ |

> スコアロジックは独立した純粋関数として実装する（テスト容易性のため）

## 覗き見防止（ローカルモード）

**プレイヤーコール画面**で実現する。

1. 入力前にプレイヤーコール画面を表示し、入力者の名前と役割を明示
2. タップするまで入力UIは表示されない
3. 入力確定後は即座に次の人のプレイヤーコール画面に遷移
4. 入力画面では他人の回答を表示しない

## 関連モデル

> データモデルの定義は [data_model.md](../../data_model.md) を参照

- GameSession: セッション全体の状態管理
- Turn: 各ターンの情報
- Answer: 各予想者の予想と得点
