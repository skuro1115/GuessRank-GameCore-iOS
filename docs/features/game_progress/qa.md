# ゲーム進行 — テストケース

## 正常系

| # | テスト内容 | 操作 | 期待結果 |
|---|---|---|---|
| N-01 | ターン開始表示 | ゲーム開始 | ターン1、正しい出題者が表示 |
| N-02 | お題表示 | お題を見るタップ | お題と3つの選択肢が表示 |
| N-03 | 出題者の正解入力 | 順位を並べ替え → 確定 | 正解が設定される |
| N-04 | 端末回し | 回答を集めるタップ | 次の回答者名が表示される |
| N-05 | 回答入力 | 準備OK → 順位選択 → 確定 | 確認画面に遷移 |
| N-06 | 回答確認・送信 | 送信タップ | 次の回答者への端末回し画面 or 結果画面 |
| N-07 | ターン結果表示 | 全員回答後 | 正解と各プレイヤーのスコアが表示 |
| N-08 | 次ターン遷移 | 次のターンへタップ | ターン番号が進み、次の出題者が表示 |
| N-09 | 最終ターン完了 | 最終ターンの結果画面 | 「結果を見る」ボタン表示 |
| N-10 | 出題者ローテーション | 3人3ターン | 各プレイヤーが1回ずつ出題 |
