# お題ブロック — UI

## ブロック操作 (`TopicView`)

### コンテキストメニュー

`showTopic` フェーズで質問テキストを長押しすると表示される。

```
ブロック: 不適切      （hand.raised）
ブロック: つまらない  （hand.raised）
ブロック: その他      （hand.raised）
理由なしでブロック    （hand.raised.slash, destructive）
```

選択するとブロックストアに登録され、即座にお題が別のものに差し替わる。
画面上部に「お題をブロックしました」のフィードバックバナーが約1.5秒表示される。

### `rankingInput` フェーズでの挙動

`showTopic` 以外ではコンテキストメニューを開いても、`viewModel.blockCurrentTopic` は no-op となる。

## ブロック管理 (`TopicSettingsView` セクション)

ゲーム設定画面のギアアイコンから開くシート内に「ブロック中のお題」セクションがある。

### 構成

```
セクション「ブロック中のお題（{N}件）」
├─ ブロック中なし: 「ブロック中のお題はありません」
├─ ブロック中あり: 各エントリ
│   ├─ 質問文（topic_lookup から取得; 見つからない場合は ID）
│   ├─ 理由（ある場合のみ caption）
│   └─ 解除 ボタン（個別解除）
└─ 全て解除（destructive、確認アラート付き）
```

### 操作

| 操作 | 動作 |
|---|---|
| 解除 タップ | `TopicBlockStore.unblock(_:)` を呼び該当エントリを削除、リストを再描画 |
| 全て解除 タップ | 確認アラートを表示 |
| 確認アラート「解除」 | `TopicBlockStore.clearAll()` を呼び全件削除、フィードバック表示 |

### フッターテキスト

「ブロック中のお題は今後のゲームで選ばれません。お題画面の「・・・」メニューからブロックできます。」
