# お題ブロック — 仕様

> ゲームルール全体は [game_rules.md](../../game_rules.md) を参照

## 概要

不適切・つまらないと感じたお題をユーザー操作でブロックし、以降のゲームで表示されないようにする。設定画面から個別／一括でブロック解除が可能。

## ビジネスルール

1. お題画面（`showTopic` フェーズ）で長押しコンテキストメニューからブロック可能
2. ブロック理由は任意（不適切 / つまらない / その他 / 理由なし）
3. ブロック実行時、現在のお題は即座に別のお題に差し替えられる（`passTopic` を内部で呼ぶ）
4. ブロックされたお題IDは新規セッションの初期 Topic 候補から除外される
5. お題変更（パス）時もブロック対象は除外される
6. ブロック解除は設定画面の「お題管理」シートから個別／一括で実行可能

## 制約

- ブロックは永続化（Documents 配下の JSON ファイル）
- 同一お題IDの再ブロックは重複させない（最新の理由・日時で上書き）
- `showTopic` 以外のフェーズではブロック操作は無視される
- フィルタ後の候補が空になる場合は、ゲーム継続のため除外を無視してフォールバック選出する

## データ

| プロパティ | 型 | 説明 |
|---|---|---|
| topicId | String | ブロック対象のお題ID |
| reason | TopicBlockReason? | 理由（任意） |
| blockedAt | Date | ブロック日時 |

### TopicBlockReason enum

| 値 | 表示名 |
|---|---|
| inappropriate | 不適切 |
| boring | つまらない |
| other | その他 |

## 状態遷移

```
showTopic フェーズ
    ↓ 長押し → コンテキストメニュー
    ↓ 理由を選択（または「理由なしでブロック」）
ブロックストアに登録 → passTopic → 別のお題が選ばれる
```

## 関連モデル / 実装

> データモデルの定義は [data_model.md](../../data_model.md) を参照

- `TopicBlockStore`（Service）: 永続化と CRUD
- `BlockedTopic`（Model）: 永続化レコード
- `GameProgressViewModel.blockCurrentTopic(reason:)`: ブロック登録 + お題差し替え
- `TopicView`: 質問テキストへの長押しコンテキストメニュー
- `TopicSettingsView`: ブロック一覧と解除 UI
