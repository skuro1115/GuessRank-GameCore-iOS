# 通信設定 — 仕様

## 概要

プレイモードを選択する画面。MVPではローカルモード固定。

## ビジネスルール

1. MVPではローカルモード（1台共有）のみ選択可能
2. 通信設定はゲーム設定より **先に** 行う（人数がモードで決まるため）
3. 将来の複数台モードでは、ホスト/ゲストの選択が追加される

## 画面フロー

### ローカル（MVP）

```
通信設定 → ゲーム設定 → プレイヤー入力
```

### 複数台（将来）

```
通信設定 → 接続 → ゲーム設定（ホストのみ）
```

## 通信モード一覧

| モード | 説明 | MVP |
|---|---|---|
| local | 1台を回してプレイ。通信なし | 対象 |
| network | ホストがルーム作成、ゲストが参加。Firebase同期 | Phase 2 |
| bluetooth | 近距離通信。オフライン対戦 | Phase 3 |

> 優先順位: ネット > Bluetooth（Bluetoothは実装コスト高）
