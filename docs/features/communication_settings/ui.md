# 通信設定 — UI定義

## 画面名

CommunicationSettingsScreen

## レイアウト

### MVP（ローカル固定）

```
┌─────────────────────────┐
│  プレイモード選択          │
│                         │
│  ● ローカル（1台で遊ぶ）   │
│  ○ ネットワーク（準備中）   │  ← disabled
│  ○ Bluetooth（準備中）    │  ← disabled
│                         │
│  [次へ]                  │
└─────────────────────────┘
```

## 表示項目

| 項目 | 型 | 表示形式 |
|---|---|---|
| プレイモード | RadioGroup | 3択（1つのみ有効） |

## 操作

| 操作 | 動作 |
|---|---|
| ローカル選択 | ローカルモードを選択（デフォルト） |
| 次へタップ | ゲーム設定画面へ遷移 |

## テキスト

| 場面 | テキスト |
|---|---|
| 画面タイトル | 「プレイモード選択」 |
| ローカル説明 | 「1台の端末をみんなで回して遊びます」 |
| 未実装モード | 「準備中」 |

## 遷移

| トリガー | 遷移先 |
|---|---|
| 次へタップ | GameSettingsScreen |
