# お題履歴 — UI

## 画面: お題管理シート

ゲーム設定画面のツールバー右上「ギアアイコン」から開くシート（`TopicSettingsView`）。

### 構成

```
ナビゲーションバー
├─ タイトル: お題管理
└─ 右上: 閉じる

セクション「枯渇通知」（条件付き表示）
├─ 全消化: 「全てのお題をプレイ済みです」+ オレンジ警告アイコン
└─ 残り少: 「残り N 件のお題で全てプレイ済みになります。」+ 黄色注意アイコン

セクション「お題履歴」
├─ プレイ済みお題: {N} / {Total}件（チェックマークアイコン）
└─ 履歴をリセット（destructive、playedCount==0 で disabled）

セクション「ブロック中のお題」「面白いお題」「データエクスポート」
└─ （別機能 topic_feedback を参照）
```

### 枯渇判定ロジック

| 状態 | 条件 |
|---|---|
| 通常 | `playedCount < total - max(5, total/20)` |
| 残り少 | `playedCount >= total - max(5, total/20)` かつ `playedCount < total` |
| 枯渇 | `playedCount >= total` |

`total` は `TopicService.totalTopicCount`。

### 操作

| 操作 | 動作 |
|---|---|
| 履歴をリセット タップ | 確認アラートを表示 |
| 確認アラート「リセット」 | `TopicHistoryStore.clear()` を呼び全件削除、フィードバックメッセージを下部に表示 |
| 確認アラート「キャンセル」 | 何もしない |

### 表示テキスト

- フッター: 「プレイ済みのお題は次回ゲームで重複しないよう自動的に避けます。リセットすると全てのお題が再び選ばれる対象になります。」
- アラート本文: 「プレイ済みのお題リストが空になります。元に戻せません。」
- 完了フィードバック: 「履歴をリセットしました」
