# 結果発表画面 — UI定義

> デザイン方向: **案C（カード＋余白重視）**を採用。探索の経緯と実装引き継ぎは
> `design_explore.md` を参照。設計原則: **全プレイヤーの得点が「理解度」として
> 意味を持つため、1位を過度にフィーチャーしない**（順位差は控えめに示す）。

## 画面名

EndScreen（`EndView.swift`）

## レイアウト

```
┌─────────────────────────────┐
│         ゲーム結果            │  ← ナビゲーションタイトル / 右上に[もう1回]
│                             │
│ ┌─────────────────────────┐ │
│ │ 🥇  じろう        250点  │ │  ← 全順位カードは共通地（1位偏重の塗り分けなし）
│ │      ⭐2回  🔥最高90点   │ │  ← プレイヤーごとのインライン統計
│ ├─────────────────────────┤ │
│ │ 🥈  はなこ        180点  │ │
│ │      ⭐1回  🔥最高70点   │ │
│ ├─────────────────────────┤ │
│ │ 🥉  たろう        120点  │ │
│ │      ⭐0回  🔥最高50点   │ │
│ └─────────────────────────┘ │
│                             │
│ ┌──────────┐ ┌──────────┐   │
│ │👥 相性分析 →│ │💬 お題分析 →│  ← 分析画面への導線
│ └──────────┘ └──────────┘   │
└─────────────────────────────┘
```

### 同点の場合

同一スコアは同順位で表示（例: 1位・1位・3位）。順位差の視覚強調は控えめなため、
同点でもレイアウトは崩れない。

## 表示項目

| 項目 | 型 | 表示形式 |
|---|---|---|
| 順位ラベル | int | 1〜3位はメダル 🥇🥈🥉 / 4位以降は「{n}位」 |
| プレイヤー名 | String | そのまま（1位のみ太字、他は medium） |
| スコア | int | 「{score}点」 |
| パーフェクト回数 | int | 「{n}回」＋ `star.fill` |
| 最高ターン得点 | int? | 「最高{score}点」＋ `flame.fill`（無ければ非表示） |

## 操作

| 操作 | 動作 |
|---|---|
| もう1回タップ（右上ツールバー） | プレイヤーを引き継いで GameSettingsScreen へ遷移 |
| 相性分析タップ | CompatibilityAnalyticsView へ遷移 |
| お題分析タップ | TopicAnalyticsView へ遷移 |

## テキスト

| 場面 | テキスト |
|---|---|
| ナビゲーションタイトル | 「ゲーム結果」 |
| もう1回ボタン | 「もう1回」 |
| 相性分析リンク | 「相性分析」 |
| お題分析リンク | 「お題分析」 |

## 配色（brand.md トークン）

| 要素 | トークン |
|---|---|
| カード地（全順位共通） | `--gr-bg-card` |
| 得点・強調 | `--gr-accent` |
| パーフェクト⭐️ | `--gr-gold`（要検討） |
| 相性分析アクセント | `--gr-pink` |
| 補助テキスト | `--gr-text-secondary` |
| 角丸 | カード `--gr-radius-md` / 分析リンク `--gr-radius-lg` |

## 遷移

| トリガー | 遷移先 |
|---|---|
| もう1回タップ | GameSettingsScreen（プレイヤー引き継ぎ） |
| 相性分析タップ | CompatibilityAnalyticsView |
| お題分析タップ | TopicAnalyticsView |
