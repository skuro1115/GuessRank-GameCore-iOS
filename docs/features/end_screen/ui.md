# 終了画面 — UI定義

## 画面名

EndScreen

## レイアウト

```
┌─────────────────────────┐
│  🏆 結果発表              │
│                         │
│  1位  じろう    250点     │  ← 強調表示
│  2位  はなこ    180点     │
│  3位  たろう    120点     │
│                         │
│  ─────────────────────  │
│  サイクル: 2             │
│  総ターン: 6             │
│                         │
│  [もう1回]  [終了]       │
└─────────────────────────┘
```

### 同点の場合

```
│  1位  じろう    250点     │
│  1位  はなこ    250点     │
│  3位  たろう    120点     │
```

## 表示項目

| 項目 | 型 | 表示形式 |
|---|---|---|
| 順位 | int | 「{n}位」 |
| プレイヤー名 | String | そのまま表示 |
| スコア | int | 「{score}点」 |
| サイクル数 | int | ゲーム設定から |
| 総ターン数 | int | サイクル × 人数 |

## 操作

| 操作 | 動作 |
|---|---|
| もう1回タップ | GameSettingsScreen へ遷移 |
| 終了タップ | CommunicationSettingsScreen へ遷移 |

## テキスト

| 場面 | テキスト |
|---|---|
| 画面タイトル | 「結果発表」 |
| もう1回ボタン | 「もう1回」 |
| 終了ボタン | 「終了」 |

## 遷移

| トリガー | 遷移先 |
|---|---|
| もう1回タップ | GameSettingsScreen（プレイヤー引き継ぎ） |
| 終了タップ | CommunicationSettingsScreen |
