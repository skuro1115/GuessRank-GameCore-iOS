# 終了画面 — 仕様

> ゲームルール全体は [game_rules.md](../../game_rules.md) を参照

## 概要

ゲーム終了後に最終順位・総合スコアを表示し、再戦への導線を提供する。

## ビジネスルール

1. 全ターン完了後に表示される
2. プレイヤーをスコア降順でランキング表示
3. 同点の場合は同順位（プレイヤー順で並べる）
4. 再戦はゲーム設定画面に戻る（プレイヤー情報は引き継ぎ可能）

## 表示内容

| 項目 | 説明 |
|---|---|
| 最終順位 | スコア降順のランキング |
| 各プレイヤーのスコア | 累計得点 |
| 1位の強調表示 | 優勝者を目立たせる |

## 操作

| 操作 | 動作 |
|---|---|
| もう1回 | ゲーム設定画面に遷移（同じメンバーで再設定） |
| 終了 | アプリのホーム or 通信設定画面に戻る |

## 関連モデル

> データモデルの定義は [data_model.md](../../data_model.md) を参照

- GameSession: 全ターンの結果を集計
- Player: スコア表示
