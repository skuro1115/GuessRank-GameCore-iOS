GuessRank サポート

ランキング予想パーティーゲーム

アプリについて

GuessRank は、友達のTop3ランキングを予想して盛り上がるパーティーゲームです。1台の端末を回して全員が参加でき、ダウンロード後すぐに遊べます。

プライバシーポリシー

最終更新日: 2025年5月1日

はじめに

黒田志音（以下「開発者」）は、GuessRank（以下「本アプリ」）におけるユーザーのプライバシーを尊重し、保護することをお約束します。本ポリシーは、本アプリにおける情報の取り扱いについて説明するものです。

収集する情報

本アプリは、個人情報を一切収集しません。

  • 氏名、メールアドレス、電話番号などの個人を特定できる情報は収集しません
  • 位置情報、連絡先、写真へのアクセスは行いません
  • アカウント登録やログインは不要です

データの保存

ゲームの設定、履歴、分析結果などのデータは、すべてお使いの端末内にのみ保存されます。外部サーバーへの送信は一切行いません。

第三者への共有

本アプリはデータを収集しないため、第三者への情報共有、販売、提供は一切行いません。

分析ツール・広告

本アプリは、サードパーティの分析ツール（アナリティクス）や広告SDKを使用していません。

お子様のプライバシー

本アプリは特定の年齢層を対象としたものではありませんが、個人情報を一切収集しないため、お子様が利用された場合でもプライバシー上のリスクはありません。

ポリシーの変更

本ポリシーは、必要に応じて更新される場合があります。重要な変更がある場合は、本ページにて通知します。最新版は常にこのページで確認できます。

お問い合わせ

プライバシーに関するご質問は、下記の「お問い合わせ」セクションからご連絡ください。

よくある質問

  • 何人で遊べますか？
    2〜8人で遊べます。1台の端末を回して全員が参加します。
  • アカウント登録は必要ですか？
    いいえ。ダウンロード後すぐに遊べます。
  • お題が合わない場合は？
    ゲーム中いつでも「お題を変える」ボタンでスキップできます。回数制限はありません。
  • 1ゲームの所要時間は？
    約5〜15分です。プレイヤー数やサイクル数で調整できます。

バグの報告、機能のリクエスト、その他ご質問は GitHub Issues からお願いします。
