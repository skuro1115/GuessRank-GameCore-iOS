GitHub Issues で報告する

よくある質問

  • 何人で遊べますか？
    2〜8人で遊べます。1台の端末を回して全員が参加します。
  • アカウント登録は必要ですか？
    いいえ。ダウンロード後すぐに遊べます。
  • お題が合わない場合は？
    ゲーム中いつでも「お題を変える」ボタンでスキップできます。回数制限はありません。
  • 1ゲームの所要時間は？
    約5〜15分です。プレイヤー数やサイクル数で調整できます。

プライバシー

GuessRank は個人情報を収集しません。すべてのゲームデータは端末内にのみ保存され、外部サーバーへの送信は一切行いません。

アプリについて

友達のTop3ランキングを予想して盛り上がるパーティーゲームです。「え、そっちが1位なの！？」という驚きと会話が自然に生まれます。
