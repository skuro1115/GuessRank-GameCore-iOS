# ペルソナ定義

---

## ペルソナ1: ユウキ（盛り上げ役）

| 項目 | 内容 |
|---|---|
| 年齢 | 24歳 |
| 職業 | 営業職 |
| 性格 | 社交的、ノリが良い、仕切りたがり |
| スマホ利用 | SNS中心、ゲームアプリは軽めのものだけ |

### 利用シーン
飲み会で「なんかやろうぜ」と場を仕切りたい。話のネタになるゲームを探している。
準備ゼロで始められて、全員が参加できるものがいい。

### このアプリに求めること
- **すぐ始められる**: ダウンロード後、説明なしで遊べる
- **盛り上がる**: 「えー、そっちが1位なの！？」というリアクションが生まれる
- **全員参加**: 見てるだけの人が出ない

### フラストレーション
- ルール説明が長いゲームは敬遠される
- 端末回しの待ち時間が長いとダレる
- お題がつまらないと一気に冷める → **「お題を変える」で即対応できることが重要**

---

## ペルソナ2: サキ（観察者タイプ）

| 項目 | 内容 |
|---|---|
| 年齢 | 22歳 |
| 職業 | 大学生 |
| 性格 | 控えめ、観察力が高い、人の好みを覚えている |
| スマホ利用 | カジュアルゲーム好き、UIにうるさい |

### 利用シーン
友達の集まりで誘われて参加。自分からは言い出さないが、
「あの人の好みわかるかも」という自信がある。
勝てるゲームなら本気を出す。

### このアプリに求めること
- **知識が活きる**: 友達をよく知っている人が有利になる仕組み
- **考える楽しさ**: 直感だけでなく、相手の性格を考えて予想する面白さ
- **結果が明快**: 自分がどれだけ当たったか一目でわかる

### フラストレーション
- 運ゲーに感じると冷める（予想に意味がないと嫌）
- 答えようがないお題だと考える楽しさが消える → **お題の質がゲーム体験を左右する**
- 結果画面が地味だと達成感がない
- 入力UIが使いにくいとストレス

## ペルソナ3: タケシ（ライトユーザー）

| 項目 | 内容 |
|---|---|
| 年齢 | 28歳 |
| 職業 | エンジニア |
| 性格 | マイペース、ゲームは好きだが面倒くさがり |
| スマホ利用 | ニュースとYouTube中心、新しいアプリは入れたがらない |

### 利用シーン
友人に「ちょっとこれやろう」と端末を渡される。
自分ではインストールしない。ルール説明は最小限で理解したい。

### このアプリに求めること
- **操作が簡単**: 渡された瞬間にやることがわかる
- **短時間で終わる**: 1ゲーム5〜15分で完結
- **意外な発見**: 「へー、お前そっち派なんだ」という会話のきっかけ

### フラストレーション
- 画面遷移が多いと「まだ？」となる
- 気まずいお題が出ると場が微妙になる → **誰でも気軽にお題を変えられる安心感が必要**
- 自分の番が来るまで暇
- 他人の入力中にスマホを見れないのが退屈

## ペルソナ活用ガイド

### 設計判断に迷ったとき

| 判断 | 参考ペルソナ |
|---|---|
| 「この機能は必要？」 | ユウキ: 飲み会で使うか想像する |
| 「UIは伝わる？」 | タケシ: 初見で迷わないか確認する |
| 「ゲーム性は十分？」 | サキ: 考える余地があるか確認する |
| 「場が冷めない？」 | 全員: お題が不適切なとき即座に変えられるか |

### MVP で特に意識すること

- **ユウキ基準**: 30秒以内にゲーム開始できること
- **タケシ基準**: 端末を渡されたら説明なしで入力できること
- **サキ基準**: 結果画面で「当たった！」という達成感があること

### 円滑に楽しめるための安全弁

ゲームはパーティの「場」で遊ぶものであり、場の雰囲気を壊す要素は即座に回避できるべき。

- **お題を変える機能**: 答えにくい・気まずい・つまらないお題は回数制限なしで変更可能。ゲームルールではなく、場を円滑にするためのオプション
- **ゲーム中断機能**: 途中で終わりたくなったら✕ボタンでいつでも中断可能
- **ルール説明画面**: 初めての人がいても、アプリ内で確認できる
