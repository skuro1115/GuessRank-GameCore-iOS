# プロジェクト概要

## アプリ名

GuessRank

## コンセプト

お題に対するランキング予測パーティーゲーム。
ターゲットが出すお題に対して、他プレイヤーが順位を予想し、一致度でスコアを競う。

> 「友達の価値観がわかる」体験を提供する

## ターゲットユーザー

- 友人グループでのパーティー・飲み会
- オフラインで集まっているが、ゲームのきっかけが欲しい人
- 価値観の違いを楽しみたい人

> 詳細なペルソナは [personas.md](personas.md) を参照

## MVP目標

- ローカル（1台共有）でゲームが完結すること
- ゲームループ（設定 → 出題 → 入力 → 結果 → 次ターン → 終了）が動くこと
- 「またやりたい」と思える最小体験を検証

## KPI（MVP）

| 指標 | 目標 |
|---|---|
| 1ゲームの完走率 | 80%以上 |
| 「もう1回」ボタン押下率 | 30%以上 |
| 1セッションあたりの平均サイクル数 | 2以上 |

## 開発方針

- **ローカルから始める** — 通信は後回し、ゲームロジックを先に固める
- **ロジックとUIを分離** — ゲームロジックは純粋関数化、スコア計算は独立
- **段階的に拡張** — 状態はCodable準拠で持ち、将来の通信対応に備える
- **早く出す** — 完璧より動くものを優先
