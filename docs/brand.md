## Font

**Noto Sans JP** (Google Font)

- 見出し: Bold / SemiBold
- 本文: Regular / Medium
- 数字・英字: Rounded系のウェイトで親しみやすさを演出

選定理由: 日本語の可読性が高く、カジュアルかつ整った印象。App Storeスクリーンショットでの視認性も良い。

## Feature List（優先順）

1. **友達の価値観がわかるパーティーゲーム** — お題に対する友達のTop3ランキングを予想する
2. **誰が一番友達を知っているか競える** — スコアで「理解度」が可視化される
3. **30秒で開始、準備ゼロ** — ダウンロード後すぐ遊べる、ルール説明不要
4. **1台で全員参加** — 端末を回すだけ、アカウント登録なし
5. **お題は自由に変更OK** — 気まずい・つまらないお題はワンタップでスキップ

## #1 Selling Point

> **「友達の意外な一面が見える」体験**

単なるクイズではなく、「え、そっちが1位なの！？」という驚きと会話が自然に生まれる。
ゲーム後に「なんでそれ1位なの？」と会話が盛り上がる — これが最大の価値。
